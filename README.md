Práctica: Método de Gauss (Unidad 3)

-Desarrollo del algoritmo del Método de Gauss con un diseño modular en Java para la materia de Métodos Numéricos

-Lenguaje de Programación
Lenguaje: Java

-Instrucciones para la compilación y ejecución del programa
Paso 1: Ubicación en el directorio de trabajo
Acceda a la carpeta raíz del proyecto desde la terminal utilizando el comando cd seguido de la ruta correspondiente al directorio donde se almacenan los archivos fuente.

Paso 2: Compilación del código fuente
Traduzca los archivos del código fuente a bytecode ejecutable mediante el comando de compilación correspondiente al paquete y directorio del proyecto. La ausencia de mensajes de error en la consola confirmará el éxito de este proceso.

Paso 3: Ejecución del programa
Ejecute la clase principal encargada de coordinar la lógica del sistema para procesar los cálculos e imprimir los resultados numéricos en la consola.

Ejemplo de PruebaSistema de Ecuaciones / Matriz de Entrada:
El programa resuelve el siguiente sistema de ecuaciones mediante eliminación gaussiana y sustitución regresiva:
3.0x_1 - 0.1x_2 - 0.2x_3 = 7.85

0.1x_1 + 7.0x_2 - 0.3x_3 = -19.3

0.3x_1 - 0.2x_2 + 10.0x_3 = 71.4

Salida esperada en consola:
Al ejecutar el programa, obtendrás los siguientes resultados:
     Soluciones del Sistema
x1 = 3.0
x2 = -2.5
x3 = 7.0
